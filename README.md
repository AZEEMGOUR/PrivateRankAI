\# PrivateRankAI



PrivateRankAI is an enterprise document retrieval and reranking system built with Python, PyTorch, and Qwen3.



\## Current Progress



\- GPU setup completed

\- Qwen3 Reranker baseline running

\- Query-document relevance test successful

\- GitHub repository initialized



\## Baseline Test



Query:



> How many paid leaves can an employee take?



The reranker correctly ranked the relevant paid-leave document above a very similar unpaid-leave document.



\## Tech Stack

\- Sentence Transformers

\- Qwen3 Reranker
